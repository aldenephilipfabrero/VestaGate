# 📷 Quick Reference: Viewing Violation Images

## For Admins - 3 Easy Steps to View Violation Images

### Step 1: Open Admin Dashboard
Navigate to: `http://yourserver/school_gate/index.php`

### Step 2: Select a Student
- Scroll through the student list on the left
- Click on any student name
- Student details appear on the right panel

### Step 3: View Violations with Images
Look for violations with the **📷 camera icon** next to them:
```
Date              Violation Type           
2026-04-23        Improper Uniform 📷
2026-04-22        ID Not Visible 📷
```

**Click on any violation with 📷 to view the full image!**

## 📊 Understanding the Image Indicators

### 📷 Camera Icon Meanings:
- **📷 Present** = Image was captured and saved
- **No icon** = No image available for this violation
- **Click to view** = Interactive modal opens with full image

### Image Information:
Each image shows:
- ✅ Full-size violation photo
- ✅ Date of violation
- ✅ Type of violation
- ✅ Student identification info

## 🎯 Common Tasks

### Task 1: Review Today's Violations with Evidence
1. Select a student → See "Today's Violation" card on right
2. Look for 📷 icons
3. Click to review evidence photo

### Task 2: Check Student History
1. Select student → Click "VIEW HISTORY"
2. All violations listed chronologically
3. Click any 📷 to see evidence

### Task 3: Identify Repeat Violators
1. Check "Violations" card for multiple 📷 icons
2. Student with many 📷 is repeat violator
3. Review images to identify pattern

### Task 4: Print Evidence
1. Open image in modal
2. Right-click image → "Save image as..." or "Print"
3. Save to computer or print directly

## 💡 Tips & Tricks

### 🔍 Finding Image Violations Quickly
- Violations with 📷 always have images
- No 📷 = No image available
- Most recent violations usually have images

### 📱 Viewing on Different Devices
- **Desktop/Laptop** - Full modal with large image
- **Tablet** - Responsive modal, fits screen
- **Mobile** - Image scales to fit screen

### 🖨️ Printing Evidence
1. Click violation with 📷
2. Modal opens with image
3. Right-click → "Print"
4. Choose printer and print

### 💾 Exporting/Saving
1. Right-click image in modal
2. Select "Save image as..."
3. Choose location on your computer
4. Use for reports or documentation

## ❓ Frequently Asked Questions

**Q: Why don't all violations have images?**  
A: Some older violations were recorded before the image feature was added. New violations will have images.

**Q: Can I view multiple images at once?**  
A: No, the modal shows one image at a time. Close and open another.

**Q: Are images permanently stored?**  
A: Yes, unless admin deletes manually or archival policy is configured.

**Q: Can I delete images?**  
A: Images are currently stored and displayed. Contact system admin for deletion.

**Q: What if image won't load?**  
A: Check your internet connection or contact IT support.
